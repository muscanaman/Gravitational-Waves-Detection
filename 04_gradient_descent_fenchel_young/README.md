# 04 - Gradient Descent on Separable Data: Fenchel-Young Losses and the Margin Condition

Independent derivation and extension of the convergence theory in
Bao, Sakaue & Takezawa (NeurIPS 2025), *"Any-stepsize Gradient Descent for Separable
Data under Fenchel-Young Losses."* (Originally developed in the standalone repository
`Gradient_Descent_From_Scratch`, now imported here with its history.)

**Status:** active, independent research exploration, not a finished result.

## 1. Why this study belongs in a GW detection repository

Every classifier in the GW pipeline is trained by minimising a loss with gradient descent:
glitch classification (study 03 uses softmax cross-entropy), signal-vs-noise detection and
parameter estimation. Whether training converges, how fast, and what the learned model
looks like are properties of the *loss* and the *data*, not of any one architecture.

This study analyses that behaviour in a setting where it can be proved:

- **The loss family.** Fenchel-Young losses are generated by a convex potential. Softmax
  cross-entropy is the member generated by the Shannon-entropy potential, so this theory
  covers the loss used in study 03.
- **The data assumption.** The 2025 theorem needs a **uniform margin condition**: every
  point must individually satisfy a fixed confidence threshold for all time. GW strain is
  low-SNR and non-stationary, with noise layered from several drifting sources (see
  study 01 on PSD and whitening), so a pointwise condition is an unrealistic fit.
- **The proposed relaxation.** Replace the uniform margin with a **Cesaro (running-average)
  margin condition**. The exact statement is in `notes/03_GD_FYLoss_FreundSchapire_Extension.docx`.

## 2. The core question

> Freund & Schapire (1999) already relax the perceptron's uniform margin condition to an
> aggregate one. Does that make a similar relaxation for the 2025 Fenchel-Young
> convergence theorem redundant?

**Short answer: no.** The two relaxations differ in:

| Aspect | Freund & Schapire (1999) | This study |
|---|---|---|
| Algorithm analysed | Discrete mistake-counting perceptron | Continuous gradient descent |
| Quantity bounded | Number of mistakes | Convergence rate to a loss value |
| Type of relaxation | Fixed, one-shot aggregate margin | Time-varying running average |
| Loss family | Hinge loss | Full Fenchel-Young family |

## 4. Connection to the other studies in this repository

- **Study 03 (glitch classification):** Koyama et al. report training loss falling to
  about zero while validation loss rises after the first few epochs. Gradient descent on
  data a model can fit perfectly is exactly the regime this theory studies. Whether the
  theory explains that overconfidence is a **hypothesis to test**, not a result.
- **Study 01 (matched filter, PSD, whitening):** the matched filter is the optimal linear
  detector for Gaussian noise. This study asks what training guarantees remain when a
  *learned* classifier replaces it and the noise is not stationary.

## 5. Limits to keep in mind

- The theorem concerns **linearly separable** data. Low-SNR GW data is generally *not*
  separable in raw strain, so any application to GW needs a justified feature space or an
  analysis of the non-separable case. This is an open question here.
- The Cesaro relaxation is a proposal under investigation, and its proof status is
  described in the notes.
